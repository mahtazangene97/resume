# Mahta Zangeneh — Product Manager Portfolio

Frontend-only personal portfolio built as a static site. No backend, database, or build step is required.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive visual system
- `script.js` — mobile menu, project filters, print/save CV, copy-link interaction

## Run
Open `index.html` in a modern browser, or serve the folder with any static web server.

## Notes
The public LinkedIn profile was used as the source for publicly visible facts such as current association with Fakher Holding, location, 16K followers, 500+ connections, University of Tehran, and the listed certificates. Other career/project details are presented from the portfolio context supplied in the conversation.

The portrait area is intentionally a non-personal placeholder. Replace it with the user's own profile photo when ready.
